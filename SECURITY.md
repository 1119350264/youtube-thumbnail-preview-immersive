# Security Policy

## Supported versions

Security reports are welcome for the latest version of this userscript published in this repository. Older versions may not receive fixes; please update to the latest reviewed release before reporting an issue when practical.

## Reporting a vulnerability

Please do not disclose API keys, personal information, or unpatched vulnerability details in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a private report. Otherwise, contact the maintainer privately through GitHub: https://github.com/1119350264. Include the affected version, a concise description, reproducible steps, and potential impact. Please allow reasonable time for investigation and a fix before public disclosure.

This project is an unofficial community-maintained userscript. It has not undergone a formal independent security audit; reports are appreciated, but no response or remediation timeline is guaranteed.
